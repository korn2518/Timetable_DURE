# 🔒 암호로 잠긴 수업 시간표 (GitHub Pages 배포용)

정적 웹페이지 3개짜리 시간표 뷰어입니다. 접속하면 숫자 암호 키패드가 먼저 뜨고,
암호가 맞아야 시간표가 보입니다.

| 파일 | 역할 |
|---|---|
| `index.html` | 잠금화면 + 시간표 뷰어 (학년별 / 전체 / 교사별 탭) |
| `maker.html` | **시간표 제작 도구.** 설정 입력 → 자동 배치 → `data.js` 내보내기 |
| `data.js` | 시간표 데이터와 암호 해시. `maker.html`이 만들어 주는 파일입니다 |
| `hash.html` | 암호만 따로 바꿀 때 쓰는 간이 도구 (배포 안 해도 됨) |

## 초기 암호

```
20261
```

배포 전에 반드시 아래 방법으로 바꾸세요.

---

## 1. 암호 바꾸기

1. `hash.html`을 브라우저로 엽니다 (더블클릭해도 됩니다).
2. 새 숫자 암호를 입력하면 두 줄이 나옵니다.
3. `data.js` 위쪽의 같은 두 줄을 그 값으로 교체합니다.

```js
"pinLength": 5,
"pinHash": "118f3e37bdbb...",
```

`pinLength`는 키패드 동그라미 개수입니다. 암호 자리수와 맞춰 주세요.

## 2. 시간표 만들기 — `maker.html`

시간표 화면 아래 **🛠 시간표 만들기** 버튼을 누르거나 `maker.html`을 직접 열면 됩니다.
접속 암호는 시간표 화면과 같습니다. 6단계로 진행합니다.

**① 기본 설정**

- 학교명 · 제목 · 학기
- 수업 요일 (월~토 중 선택)
- 1교시 시작 시각, 수업 1시간(분), **쉬는 시간(분)**, 하루 교시 수
  → 교시별 시각이 자동 계산되어 바로 아래에 표로 보입니다
- 점심시간 위치(몇 교시 후)와 길이
- 학년 수, 학년별 반 수

### 두레자연중학교 템플릿 (maker.html 버전 6.0)

**작업 순서가 단계로 나뉘어 있습니다.** 한 단계를 마치면 `저장하고 다음 ▶` 을 누르세요.
조건이 안 맞으면 이유를 알려 주고 다음으로 넘어가지 않습니다.

```
① 학교 · 시간   →   ② 교과 · 교사 · 단위수   →   ③ 고정 · 제외 · 규칙   →   ④ 시간표 배치   →   ⑤ 내보내기
```

- 화면 위 단계 막대에서 언제든 앞 단계로 돌아갈 수 있고, 끝낸 단계에는 ✓ 가 붙습니다.
- 무엇이든 고치면 화면 위에 `✓ 저장됨 14:32:07` 이 갱신됩니다.
- **④단계 맨 위에 「지금 설정」 카드**가 있어, 앞에서 정한 교시 구조·블록타임·규칙·고정·교사 시수가
  그대로 반영됐는지 배치 직전에 확인할 수 있습니다. 앞 단계를 고치고 돌아오면 이 카드가 바로 바뀝니다.

**배치가 실패하지 않습니다.** 규칙이 너무 빡빡하면 아래 순서로 조금씩 풀어 가며 반드시 결과를 내고,
무엇을 풀었는지 알려 줍니다.

> 규칙을 이만큼 풀어서 맞췄습니다 — 블록 교과 요일을 모든 요일로 · 하루 같은 과목 최대 1→2시간

정말 불가능한 경우에만 멈추고, 그때는 원인을 짚어 줍니다.

> 윤채원 선생님의 고정이 목요일 1교시에 겹칩니다
> · 정민재 선생님 주당 42시간 — 한 주에 가능한 40시간을 넘습니다
> · 2학년 : 🔗 블록타임 5자리인데 2시간 이상인 교과가 3개뿐입니다

### 기능 상세

학년당 1반, 교과 선생님이 전학년을 담당하는 구조에 맞춰져 있습니다.
아래 ②~⑥ 설명은 이전 버전 기준이며, 현재 화면은 한 장에 모두 들어 있습니다.

**교과별 입력** — 한 줄이 한 교과입니다.

| 과목 | 담당 교사 | 1학년 | 2학년 | 3학년 | 블록 | 고정·제외 |
|---|---|---|---|---|---|---|
| 국어 | 김서연 | ✓ 4 | ✓ 4 | ✓ 5 | ☐ | 설정 |

**🔒 고정 · ⛔ 제외** — 고정·제외 칸의 `설정`을 누르면 요일 × 교시 판이 열립니다.
칸을 누를 때마다 없음 → 🔒고정 → ⛔제외 로 바뀝니다.

- **🔒 고정** — 보조강사 수급 등으로 반드시 그 시간에 넣어야 하는 수업.
  자동 배치가 이 자리를 먼저 잡고 시작하며, 이후 손으로도 옮겨지지 않습니다.
- **⛔ 제외** — 고등학교 지원 등으로 그 시간에는 넣을 수 없는 수업.
  자동 배치와 손편집 모두 이 칸을 피합니다.
- 고정이 단위수보다 많거나 서로 겹치면, 배치 전에 어디가 문제인지 짚어 줍니다.
- 배치가 끝나면 `🔒 고정 3/3칸 반영` 처럼 실제로 몇 칸이 지켜졌는지 표시됩니다.
- 🧸 표준 교과로 채우거나 🚀 원클릭을 다시 눌러도 **고정·제외 표시는 과목명 기준으로 그대로 남습니다.**
  (이미 입력한 교과가 있으면 🚀 원클릭은 표를 건드리지 않고 다시 배치만 합니다)

**＊ 배치 규칙** — 자동 배치와 손으로 옮길 때 모두 지켜집니다.

- **같은 과목 최대 연속 교시** (기본 2) — 2로 두면 **3시간 이상 연강이 생기지 않습니다.**
- **같은 날 같은 과목 최대 시수** (기본 2)
- **1교시에 넣지 않을 과목**, **마지막 교시에 넣지 않을 과목** — 과목명을 쉼표로 적습니다 (예: `체육, 미술`)
- **🔗 블록타임 자리에 우선 배치할 교과** (기본 `국어, 영어, 수학, 사회, 과학, 역사`) —
  ①번에서 🔗 로 묶은 80분 연강 자리를 앞에 쓴 순서대로 이 교과들로 먼저 채웁니다.
  같은 교과의 **남은 시수는 평소처럼 한 시간씩 흩어서** 배치됩니다.
  (예: 국어 12시간 → 블록 자리에 연강 5쌍, 나머지 2시간은 단독 배치)
  해당 교과의 시수가 부족하면 자연스럽게 다른 교과로 채워집니다.
- **🎫 규칙 예외 과목** — 여기 적은 과목은 위 규칙을 적용받지 않습니다.
  3시간 연강이나 하루 여러 시간이 필요한 교과(연극·합주·프로젝트 수업 등)에 쓰세요.
  🔒 고정과 ⛔ 제외, 교사 겹침 검사는 예외 과목에도 그대로 적용됩니다.
- 요일별로 고르게 분산

**배치는 두 단계로** — 고정이 확실히 먼저 잡히도록 버튼을 나눴습니다.

1. **① 🔒 고정 먼저 배치** — 고정한 수업만 자리를 잡고 나머지는 비워 둡니다.
   `🔒 고정 6/6칸을 먼저 놓았습니다 — 1학년 음악 목1교시·목2교시 / 2학년 음악 목3교시·목4교시 …`
   처럼 어디에 놓였는지 이름으로 확인할 수 있습니다.
2. **② ▶ 나머지 자동 배치** — 화면에 놓인 것을 그대로 두고 빈 자리만 채웁니다.
   고정은 그대로 두고 나머지만 다시 뽑고 싶을 때도 이 버튼을 씁니다.
3. **⚡ 처음부터 새로 배치** — 전부 지우고 처음부터 (이때도 고정이 먼저 놓입니다).

버튼을 누르면 결과 요약이 바로 뜨고 화면이 시간표로 자동 이동합니다.

> ✓ 새로 배치했습니다 (0.4초)
> 전체 120칸 중 120칸 배치 · 빈 칸 없음 · 🔒 고정 6칸 · 🔗 블록 15칸 (우선 교과 15칸)

이 줄이 보이지 않으면 버튼이 눌리지 않은 것이니, 제목 아래 **버전 5.3** 표시를 확인하고
브라우저를 강력 새로고침(`Cmd+Shift+R` / `Ctrl+F5`) 해 주세요.

**적용되지 않는 고정을 잡아냅니다** — 단위수가 0인 학년에 고정을 걸었거나 없는 요일·교시에 표시했다면
배치 전에 이유까지 알려 줍니다 (`🔒 역사 2학년 금요일 2교시 (2학년 단위수가 0입니다)`).
예전에는 이런 표시가 조용히 무시돼서 "고정이 안 된다"고 느껴질 수 있었습니다.

**연강 고정하는 법** — 붙어 있는 두 칸을 모두 🔒 로 지정하면 됩니다.
학년마다 따로 지정하므로, 창 위쪽의 **학년 탭을 먼저 고른 뒤** 칸을 누르세요.
탭에 `1학년 🔒2/3` 처럼 그 학년에 몇 칸을 고정했는지 표시되니 실수를 바로 알 수 있습니다.

> 예) 음악을 목요일에 학년별 연강으로 — 1학년 탭에서 목 1·2교시, 2학년 탭에서 목 3·4교시,
> 3학년 탭에서 목 5·6교시를 🔒 로 지정하면 그대로 배치됩니다.

**✋ 옮기기 (퍼즐)** — 완성된 시간표에서 칸을 끌어다 놓거나, 두 칸을 차례로 누르면 자리가 맞바뀝니다.
겹치거나 규칙에 걸리면 **그 요일 안에서** 대신 놓을 자리를 자동으로 찾아 줍니다 —
빈 교시가 있으면 그쪽을 먼저 쓰고, 없으면 바꿔도 되는 다른 수업과 맞교환합니다.
어떤 이유로 어디에 놓았는지 안내가 뜹니다 (예: `임태윤 선생님이 그 시간에 3학년 수업이 있습니다 → 월요일 6교시(빈 시간)로 대신 옮겼습니다`).
그래도 자리가 없으면 아무것도 바꾸지 않고 이유만 알려 줍니다.
🔒 고정된 수업과 🔗 블록타임 자리는 잡히지 않습니다.
**요일이 달라도 됩니다** — 월요일 1교시를 금요일 3교시로 보내면 두 수업이 서로 자리를 바꿉니다.
칸을 하나 고르면 옮길 수 있는 자리에 옅은 테두리가 생깁니다.
같은 학년 안에서만 움직이고, 교사가 다른 학년 수업과 겹치거나 ⛔ 제외된 시간이면 막고 이유를 알려 줍니다.
🔒 고정된 수업은 잡히지 않습니다. `✎ 과목 바꾸기` 로 전환하면 칸을 눌러 과목 자체를 교체할 수 있습니다.

**수업 시간 설계 (①번)** — 1교시 시작 시각, 수업 1시간(분), 쉬는 시간(분), 점심 위치와 길이를 정합니다.
기본값은 두레자연중학교 일과입니다 — 09:00 시작 · 40분 수업 · 10분 쉬는 시간 · 8교시 · 4교시 후 점심 60분
(점심 12:10, 종료 16:20).

**🔗 블록타임 지정 (①번)** — 요일 × 교시 경계 표에서 이어 붙일 두 교시를 누르면 됩니다.
쉬는 시간이 사라져 **80분 연속 수업**이 되고, 그 뒤의 점심과 종료 시각이 그만큼 당겨집니다.
표 오른쪽에 그 요일의 점심 시각과 종료 시각이 바로 표시됩니다.

| 지정 | 점심 | 종료 |
|---|---|---|
| 없음 | 12:10 | 16:20 |
| 3·4교시 블록 | **12:00** | **16:10** |
| 3·4교시 + 7·8교시 블록 | 12:00 | **16:00** |

블록으로 지정한 자리에는 **같은 과목이 2시간 연속**으로 배치됩니다. 점심을 사이에 둔 묶기는 막혀 있고,
요일마다 따로 지정하므로 다른 요일은 영향을 받지 않습니다. 수업 1시간을 45분으로 바꾸면 블록은 90분이 됩니다.

시간표를 만든 뒤 결과 화면의 **🔗 연강 묶기 / 풀기** 모드에서도 같은 작업을 할 수 있습니다.

**요일별 교시 수** — ①번 설정의 `요일별 교시 수`에서 요일마다 다르게 정할 수 있습니다
(예: 수요일만 5교시). 수업이 없는 칸은 표에 `–` 로 비워지고, 학급별 필요 단위수도 자동으로 다시 계산됩니다.
`하루 교시 수 (일괄)` 을 고치면 모든 요일이 한꺼번에 바뀝니다.

**주간 전체 보기** — 요일 × 학년을 한 판에 펼칩니다. 1·2·3학년의 월~금이 한눈에 들어와
드래그로 자리를 맞추기 좋습니다. `index.html`에도 같은 보기가 기본 화면으로 들어가고,
아래에 **요일별 수업 시각** 표가 함께 나옵니다.

---

**② 과목 · 학년별 단위수**

과목을 한 줄씩 넣고, **학년마다 주당 몇 시간인지 따로** 적습니다.

| 과목명 | 1학년 | 2학년 | 3학년 | 블록타임 |
|---|---|---|---|---|
| 국어 | 4 | 4 | 5 | ☐ |
| 과학 | 3 | 3 | 3 | ☑ |

- 그 학년에 없는 과목은 **0**으로 둡니다
- 표 맨 아래 학년별 합계가 초록색이면 시수가 딱 맞는 것입니다 (`35 / 35`)
- **🧸 예시 채우기** — 중학교 표준 과목 13개를 채우고, 현재 교시 수에 맞춰 총합을 자동 조정합니다
- **📋 복사** — 1학년 단위수를 다른 학년에 그대로 복제합니다

**③ 담당 교사 · 담당 반**

단위수를 넣은 과목·학년마다 줄이 자동으로 생깁니다. **교사 성명**을 쓰고 **담당 반**을 고르세요.

- 한 학년을 두 선생님이 나눠 맡으면 **＋** 버튼으로 줄을 늘려 반을 갈라 줍니다
  (예: 1학년 국어 → 김서연 1반 / 이하늘 2반)
- 두 줄에 같은 반이 겹치면 그 반 버튼이 빨갛게 표시됩니다
- 학년 필터로 한 학년씩만 볼 수 있습니다
- **진단** 칸이 실시간으로 알려 줍니다
  - 학년별 단위수 합계가 주당 칸 수와 맞는지
  - 담당 반이 비었거나 두 교사에게 겹쳐 배정된 곳
  - 교사 성명이 비어 있는 줄
  - 주당 한도를 넘는 교사, 시수가 많아 배치가 빡빡한 교사
  - 블록 과목인데 단위수가 2 미만이라 묶을 수 없는 경우

**④ 블록타임**

블록타임(2시간 연속)을 **어느 요일에** 허용할지, **몇 교시~몇 교시** 사이에 둘지 정합니다.
과목 표에서 `블록`에 체크한 과목만 대상이고, 점심시간을 사이에 두고는 묶이지 않습니다.
'같은 날 같은 과목 중복 금지', '요일별 고르게 분산' 규칙도 켜고 끌 수 있습니다.

**⑤ 배치 · 수정**

**⚡ 자동 배치 실행**을 누르면 교사 중복 없이 모든 조건을 만족하는 시간표를 찾습니다.
마음에 안 들면 다시 눌러 다른 안을 뽑으세요. 칸을 클릭하면 과목을 바꾸거나 비울 수 있고,
다른 반과 교사가 겹치는 과목에는 경고가 붙습니다. **🔎 충돌 검사**로 최종 점검합니다.

> 배치를 못 찾는다면 대개 원인은 셋입니다 — 한 교사의 시수가 너무 많음 / 블록타임 요일이 너무 적음 /
> 단위수 합계가 안 맞음. 진단 칸의 안내를 따라 조정해 보세요.

**⑥ 출력 · 내보내기**

- 학년별 · 전체 · 교사별 시간표를 미리 보고 인쇄합니다
- 접속 암호를 새로 정할 수 있습니다 (비워 두면 기존 암호 유지)
- **⬇ data.js 내려받기** → GitHub의 `data.js`를 이 파일로 덮어쓰면 배포본이 갱신됩니다
- **💾 설정 파일 저장** → 입력한 내용 전부를 담은 JSON. 다음에 불러오면 이어서 작업할 수 있습니다

입력 내용은 쓰던 브라우저에도 자동 저장됩니다. 다른 기기에서 이어 하려면 설정 파일을 옮기세요.
배포된 사이트에서 편집해도 **변경은 내 브라우저에만 남습니다.** 다른 사람에게 보이게 하려면
반드시 `data.js`를 내려받아 GitHub에 다시 올려야 합니다.

## 3. data.js를 직접 손보기

제작 도구를 쓰지 않고 파일을 바로 고쳐도 됩니다.

- `school`, `title`, `semester` — 학교명 / 제목 / 학기
- `periods` — 교시 이름과 시작·종료 시각. `"lunch": true`가 붙은 항목이 점심시간입니다.
  쉬는 시간은 앞 교시 종료와 다음 교시 시작 사이 간격으로 표현됩니다 (예: 09:50 → 10:00 = 10분).
- `grades`, `classes` — 학년과 각 학년의 반 목록
- `subjects` — 과목명, 학년별 주당 단위수(`hoursByGrade`), 학년별 담당 교사, 블록타임 여부(`block`)
- `teachers` — 교사별 시간표 탭에 나오는 교사 목록
- `timetable` — 실제 배치. `"학년-반" → 요일 → [1교시, 2교시, …]` 순서이며
  점심시간은 배열에 포함되지 않습니다. 빈 시간은 `null`로 둡니다.

```json
"2-1": {
  "월": [ {"subject":"국어","teacher":"김서연"}, null, ... ]
}
```

블록타임(2시간 연속)은 같은 과목을 인접한 두 칸에 나란히 넣으면
화면에 자동으로 「연강」 표시가 붙습니다.

## 4. GitHub Pages 배포

### 웹에서만 하는 방법 (터미널 불필요)

1. GitHub에서 새 저장소(Repository)를 만듭니다. **Public**으로 만들어야 무료로 Pages를 쓸 수 있습니다.
2. `Add file → Upload files`로 `index.html`, `maker.html`, `data.js` 세 파일을 올리고 Commit 합니다.
3. `Settings → Pages`로 이동합니다.
4. **Source**를 `Deploy from a branch`, **Branch**를 `main` / `/ (root)`로 두고 Save.
5. 1~2분 뒤 `https://<아이디>.github.io/<저장소이름>/` 주소가 뜹니다.

### 터미널로 하는 방법

```bash
git init
git add .
git commit -m "시간표 배포"
git branch -M main
git remote add origin https://github.com/<아이디>/<저장소이름>.git
git push -u origin main
```

이후 `Settings → Pages`에서 위와 같이 설정하면 됩니다.

> `hash.html`은 배포하지 않아도 됩니다. 내 컴퓨터에서만 열어 쓰는 게 더 안전합니다.

## 5. 보안 수준에 대해 (꼭 읽어 주세요)

GitHub Pages는 서버 코드를 돌릴 수 없는 **정적 호스팅**이라, 암호 검사도 브라우저 안에서 이뤄집니다.
따라서 이 잠금장치의 성격은 다음과 같습니다.

**되는 것**

- 주소를 우연히 알게 된 사람이 시간표를 그냥 보는 것을 막습니다.
- 암호 원문은 어디에도 저장되지 않습니다. SHA-256 해시만 들어 있어서
  소스를 봐도 암호 자체는 바로 알 수 없습니다.
- 검색엔진 수집을 막는 `noindex` 태그가 들어 있습니다.

**안 되는 것**

- 브라우저 개발자도구로 `data.js`를 직접 열면 **시간표 내용은 볼 수 있습니다.**
- 숫자 5자리 암호는 마음먹고 프로그램을 돌리면 뚫립니다.
- 암호를 아는 사람은 누구나 `maker.html`에 들어가 편집 화면을 볼 수 있습니다.
  (다만 저장은 그 사람 브라우저에만 되고, GitHub에 올리지 않는 한 배포본은 바뀌지 않습니다.
  이게 걱정되면 `maker.html`은 배포하지 말고 내 컴퓨터에서만 쓰세요.)

즉 **"아무나 못 보게 하는 가림막"** 수준입니다.
학생 개인정보처럼 유출되면 곤란한 내용은 올리지 마세요.
정말로 막아야 한다면 저장소를 **Private**으로 두고 Pages 대신
Google Drive 공유나 학교 업무포털처럼 로그인이 있는 곳을 쓰는 편이 안전합니다.
