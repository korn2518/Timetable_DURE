# 📱 앱으로 만들어 배포하기

> **버전 6.1 — 배포판에서 발견된 두 가지 오류를 고쳤습니다.**
>
> **① 임의 고정과목 버그** — 지정하지 않은 칸이 🔒 로 굳어 옮기기·과목 바꾸기가 모두 막히던 문제.
> 원인은 시간표 칸 자체에 `fixed` 표시를 저장해 두고, 고정을 풀어도 그 표시가 남아 있었던 것입니다.
> 이제 **칸에는 아무 표시도 저장하지 않고**, 🔒 여부는 교과표의 고정 핀에서 그때그때 계산합니다.
> 고정을 풀면 즉시 옮길 수 있고, 예전 저장값에 남아 있던 표시도 열 때 자동으로 지웁니다.
>
> **② 블록타임 교환 불가** — 🔗 로 묶은 자리는 무조건 이동이 막혀 있었습니다.
> 이제 **🔗 블록타임끼리 통째로 맞바꿀 수 있습니다** (2시간 ↔ 2시간).
> 한 시간짜리 수업과는 섞이지 않아 연강이 깨지지 않고, 교사 겹침·⛔ 제외·배치 규칙은 그대로 검사합니다.
> 블록의 어느 칸을 눌러도 두 칸이 한 덩어리로 선택됩니다.
>
> 기존에 배포한 사이트를 쓰고 계셨다면, 이 폴더의 파일로 **전부 덮어쓴 뒤** 브라우저에서
> 강력 새로고침(`Cmd+Shift+R` / `Ctrl+F5`) 해 주세요. 서비스 워커 캐시 이름도 바꿔 두었습니다.


이 폴더를 통째로 GitHub에 올리면 **웹사이트이자 설치 가능한 앱(PWA)** 이 됩니다.
휴대폰·태블릿·컴퓨터 홈 화면에 아이콘으로 설치되고, 인터넷이 끊겨도 시간표를 볼 수 있습니다.

## 폴더에 든 것

| 파일 | 역할 |
|---|---|
| `index.html` | 시간표 보기 (암호 잠금 · 주간 전체 · ✨선생님 강조) |
| `maker.html` | 시간표 만들기 (단계별 진행) |
| `data.js` | 시간표 데이터 · 암호 해시 |
| `manifest.webmanifest` | 앱 이름·아이콘·색상 정의 |
| `sw.js` | 오프라인 지원 (서비스 워커) |
| `icon-192.png` `icon-512.png` `icon-maskable-512.png` `apple-touch-icon.png` | 앱 아이콘 |
| `.github/workflows/deploy.yml` | GitHub Pages 자동 배포 |
| `.nojekyll` | 파일을 그대로 서비스하도록 하는 표시 |
| `README.md` | 프로그램 사용 설명서 |

## 1. GitHub에 올리기

### 웹에서만 (터미널 불필요)

1. GitHub에서 새 저장소를 만듭니다. **Public** 으로 만들어야 무료 Pages를 씁니다.
2. `Add file → Upload files` 로 **이 폴더 안의 파일 전부**를 끌어다 놓고 Commit 합니다.
   - 숨김 파일(`.nojekyll`, `.github`)이 안 보이면 macOS Finder에서 `Cmd + Shift + .` 를 눌러 표시하세요.
   - `.github/workflows/deploy.yml` 은 폴더째 끌어다 놓으면 경로가 유지됩니다.
3. `Settings → Pages` → **Source** 를 `GitHub Actions` 로 선택합니다.
   (워크플로 파일을 못 올렸다면 `Deploy from a branch` → `main` / `/ (root)` 로 해도 됩니다.)
4. 1~2분 뒤 `https://<아이디>.github.io/<저장소이름>/` 이 열립니다.

### 터미널로

```bash
cd "이 폴더"
git init
git add -A
git commit -m "시간표 앱 배포"
git branch -M main
git remote add origin https://github.com/<아이디>/<저장소이름>.git
git push -u origin main
```

이후 `Settings → Pages` 에서 Source 를 `GitHub Actions` 로 지정하면 끝입니다.
다음부터는 파일을 고쳐 `git push` 만 하면 자동으로 갱신됩니다.

## 2. 앱으로 설치하기

배포된 주소(`https://...`)로 접속한 뒤,

- **안드로이드 / 데스크톱 크롬·엣지** — 시간표 화면 아래 **📱 앱으로 설치** 버튼을 누르거나,
  주소창 오른쪽의 설치 아이콘을 누릅니다.
- **아이폰 / 아이패드 사파리** — 공유 버튼 → **홈 화면에 추가**.

설치하면 주소창 없는 전용 창으로 열리고, 홈 화면에 시간표 아이콘이 생깁니다.

> `file://` 로 파일을 직접 열 때는 앱 설치와 오프라인 기능이 동작하지 않습니다 (브라우저 정책).
> 그래도 시간표 보기·만들기는 그대로 됩니다.

---

## 3. ✨ 선생님 네온 강조

시간표 화면(`index.html`)의 **주간 전체 / 학년별 / 요일별** 보기에서,

- 표 위의 **✨ 선생님 강조** 줄에서 이름을 누르면 그 선생님 수업만 네온사인처럼 빛나고
  나머지는 흐려집니다. 한 주에 어디에 들어가는지 한눈에 보입니다.
- **표 안의 칸을 눌러도** 같은 효과가 켜집니다. 다시 누르거나 **✕ 끄기** 로 해제합니다.
- 탭을 바꿔도 강조가 유지되고, 인쇄할 때는 흐림 없이 정상 출력됩니다.

## 4. 내용을 바꾸려면

1. `maker.html` 을 열어 시간표를 고칩니다.
2. ⑤단계에서 **⬇ data.js 내려받기** 를 누릅니다.
3. 내려받은 `data.js` 로 저장소의 `data.js` 를 덮어쓰고 Commit 합니다.
4. 1~2분 뒤 배포본이 갱신됩니다. 앱에서 새로고침하면 최신 시간표가 보입니다.

> 서비스 워커는 **항상 최신 파일을 먼저 받아오도록(network-first)** 만들어 두었습니다.
> 예전 화면이 남아 보이는 일은 없습니다.
